# Fulbariya Degree College Website

Premium navy/gold college website frontend scaffold.

## Important
- Supabase is intentionally NOT connected.
- Cloudinary is intentionally NOT connected.
- All public pages, shared CSS/JS, assets folders and Admin UI placeholders are included.
- Replace placeholder images in `assets/images/` with the college's real images.
- Supabase/Cloudinary integration can be added later without changing the public page structure.

## Structure
- `index.html` — homepage
- `pages/` — public pages
- `pages/admin/` — admin UI placeholders
- `css/` — shared styles
- `assets/js/` — shared frontend scripts
- `assets/images/` — image assets
- `assets/icons/` — icons
- `assets/documents/` — notices/PDFs

## Current public routes
Home, About, Academics, Admission, Results, Student Portal, Notices, Teachers,
BNCC, Scouts, Blood Donation, Activities, Gallery and Contact.

## Design
Premium institutional navy/gold visual system, responsive navigation, hero slider,
cards, glass effects, compact sections, accessible buttons, mobile navigation,
reveal animations and reusable components.
